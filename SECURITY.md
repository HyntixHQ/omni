# Security Policy

## Reporting a Vulnerability

Do not open public GitHub issues for security vulnerabilities. Instead, report
them to the project maintainers directly.

To report a security issue, please contact <dev@hyntix.com> with a
description of the issue, the steps you took to create the issue, affected
versions, and, if known, mitigations for the issue.

You should receive a response within 48 hours. If you do not receive a response,
please follow up to ensure the message was received.

## Preferred Languages

We prefer all communications to be in English.
